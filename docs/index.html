ChronoKeep

A browser extension that automatically saves every webpage you visit to the Internet Archive's Wayback Machine — with a customizable ignore list for privacy and real-time archiving feedback.

  • Automatic background archiving to the Wayback Machine
  • Per-site ignore list keeps private pages out of the archive
  • Real-time archive status in the toolbar popup
  • No account, no tracking — talks only to web.archive.org
